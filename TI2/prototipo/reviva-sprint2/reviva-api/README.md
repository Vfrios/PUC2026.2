# Reviva API — Sprint 2

Esta API parte da base da Sprint 1 e acrescenta os contratos de chat em tempo
real, agendamento/retirada e avaliações necessários nesta etapa. Ela não inclui
o escopo completo do sistema final nem as entregas de integração da Sprint 3.

Configure `MONGODB_URI`, `MONGODB_DATABASE` e `JWT_SECRET` no ambiente antes de
executar. Não use credenciais da pasta de origem nem as inclua no repositório.
Inicie a API pela pasta raiz desta cópia:

```powershell
pnpm start:backend
```

Não compartilhe os valores das variáveis de ambiente. A API sobe em
`http://localhost:8080`.

O escopo, inventário das classes, APIs disponíveis, configuração MongoDB, critérios de aceite e instruções completas estão no [README global](../README.md).
