# Escopo do projeto

Esta pasta contém a etapa intermediária do Reviva: a base funcional da Sprint 1
mais os incrementos da Sprint 2 (aproximadamente 66% do escopo planejado). Não
é a versão final do sistema.

Use [`sprints/sprint2/Planejamento_Geral.md`](./sprints/sprint2/Planejamento_Geral.md)
para consultar o escopo e as entregas desta sprint, e [`commit.md`](./commit.md)
para as instruções de envio por responsável. A pasta `codigo-funcional` é a
referência do sistema final e não foi modificada para preparar esta versão.
