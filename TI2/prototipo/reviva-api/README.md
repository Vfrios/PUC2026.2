# Reviva API

Backend em Java 21 + Spring Boot 3. Veja o **README na raiz do projeto**
(`../README.md`) para instruções completas de como rodar o backend junto
com o frontend, mapeamento tela → endpoint e credenciais de demonstração.

Resumo rápido:

```bash
mvn spring-boot:run
```

- API: http://localhost:8080
- Swagger UI: http://localhost:8080/swagger-ui.html
- Banco: MongoDB Atlas configurado por `MONGODB_URI` e `MONGODB_DATABASE`
- Login de demonstração: `doador@reviva.com` / `receptor@reviva.com`, senha `reviva123`
