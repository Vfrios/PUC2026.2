# Reviva API — Sprint 1

Esta API pertence à cópia de escopo restrito da Sprint 1. Os fluxos ativos são autenticação, perfil inicial, consulta/publicação de itens, endereços, favoritos, comunidades, notificações básicas e conversas por mensagens de texto.

Para executar a API carregando as variáveis locais de `reviva-sprint1/.env` e `reviva-sprint1/atlas-credentials.env`, inicie-a pela pasta raiz da cópia:

```powershell
pnpm start:backend
```

Não use o projeto original nem compartilhe os valores dos arquivos de ambiente. A API sobe em `http://localhost:8080`.

O escopo, inventário das classes, APIs disponíveis, configuração MongoDB, critérios de aceite e instruções completas estão no [README global](../README.md).
